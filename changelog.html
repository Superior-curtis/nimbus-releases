Changelog

  1. 1.0 beta7
    • Same-Wi-Fi discovery now shows nearby Nimbus Macs in Settings → Friends, so you can add a friend without typing an IP address.
    • Friend connections can trust either the saved IP or the saved Mac name, fixing the “add a friend, then nothing happens” path on networks that choose IPv6 or Bonjour names.
    • Shelf items reveal in Finder with a click and drag out as explicit file URLs, so parked files no longer feel trapped.
    • Nimbus checks the public release feed for updates on launch, with a manual Check for Updates item in the app and menu-bar menus.
    • Fixed the release build so macOS reads the real minimum version as macOS 13.0, not the build machine's current macOS.
  2. 0.1.4 September 2026

    Island-only overlay

    • Fixed a bug where desktop ornaments from the demo (the launcher, hot zones, dock edges, the hidden dock) were rendering on top of your screen around the island.
    • The transparent overlay now shows only the island — the idle pill, or its home content when you open it. Nothing else leaks into the panel.
  3. 0.1.3 September 2026

    Alcove-true placement

    • The island now hangs flush with the very top edge of the screen, right at the notch / menu-bar line — not a menu-bar height below it, exactly like the original demo places it.
    • It rides at a high window layer so nothing ever stacks over it, in any app or full-screen Space.
  4. 0.1.2 September 2026

    Floating island

    • The island now lives on your real desktop — a transparent, always-on-top overlay at the top of the screen that joins every Space and never steals focus from the app you're typing in.
    • No Dock icon: Nimbus runs as a menu-bar item, and the island expands when you hover or click it — music, weather, timers, downloads, HUD and clipboard over any app.
    • Settings now live in their own window (⌘, or the menu-bar icon). First run opens it for the 1-day trial.
    • Licence keys are stored in the macOS Keychain; keys activated in 0.1.1 are carried over automatically.
    • Apple silicon (arm64) builds.
  5. 0.1.1 September 2026

    Native window

    • Real Mac window: full-size content under the traffic lights, no simulated menu bar inside the window, drag the desktop to move it.
    • Native app menu — About, Settings… and Island Panels (⌘1–⌘9), Reload (⌘R), Close (⌘W), Quit (⌘Q).
    • Right-click shows a native editing menu, never a web-view menu.
  6. 0.1.0 September 2026

    First release

    • The island: idle pill that expands into music, weather, timers, clipboard, downloads and HUD surfaces.
    • Privacy indicators — camera and microphone dots while the island is closed.
    • System Settings-style preferences with nine panels (⌘1–⌘9).
    • Keyboard control throughout, standing down while you type in a text field.
    • Licence gate: 1-day trial, one-time purchase, offline activation.
    • Apple silicon build, shipped as a DMG.
